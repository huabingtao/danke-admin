## 兼容与文件范围

- Core GET /items 隐藏归档别名，返回 aliases 和 aliasIds；旧 GET /items/:id 仍可找到正式道具，旧 ID 的更新及产出写入/查询归入正式 ID。
- 个人显示列配置读取与保存时将旧别名 ID 归一并去重；数据库中的既有配置原文不重写。浏览器列顺序也识别旧 ID，不用重置拖动设置。
- 原名称和英文名保留为搜索别名；Web 道具导入识别这些名称，避免再次创建重复项。
- 对旧别名 ID 的 DELETE 返回409并要求刷新，防止误删正式项。归档元数据受到保留字段保护，普通 stats 更新不会清除它们；原 JWT/权限检查保持不变。
- 主要文件：Admin ResourceViewTabs、GemValueEditor、gem-values页面、items页面、名称/列序及导入辅助；Core item-identity、ItemsService、分类/偏好服务、YieldsService和分类图标定义；对应测试与 Core scripts/normalize-item-definitions.py。

无数据库结构迁移，无远端部署，无现有构建产物覆盖。Web/资源仓仅只读取材。
