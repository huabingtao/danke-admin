# 游戏维度资源管理实施计划与执行记录

**Goal:** 道具库维护真实适用体系和资源类型，资源表通过统一维度查看获取情况并独立保存账号显示列。

**Architecture:** Core 是维度和偏好的唯一服务端。复用已存在的多分类和 UserViewPreference，不改表结构或道具、来源、产出 ID。Admin 使用同一维度组件和匹配函数。

- [x] 记录两仓 main 分支、近期提交和已有未提交文件；抓取数据基线、在线备份及分类核对清单。
- [x] Core resource-views 定义 9 个维度，DTO/controller/service 扩展可选 viewId；保留 all 旧键，验证目标维度成员。
- [x] 道具列表共用维度，统一 ItemEditorDialog 保存名称/图标/分类/类型；批量保持/设置/清空及确认，删除先备份。
- [x] 资源表接入快捷维度和细分，URL 恢复、各维度穿梭框候选及独立偏好，切换清空旧筛选。
- [x] 可见列和来源统一用于非零来源、合计与导出，保留行列拖动和确认编辑。
- [x] Admin 86 / Core 147 项测试、类型、相关 lint、隔离构建；真实副本 HTTP 验证；本地 Core 切换后正式数据对账。
